# Projektorganisation

## Kommunikation
Die interne Kommunikation erfolgt über Discord. Für die Kommunikation mit der Team-Betreuung (TB) und dem Auftraggeber (AG) stehen separate Kanäle zur Verfügung.

## Versionsverwaltung
Der Quellcode und die Projektdokumentation werden über GitHub verwaltet.

## Aufgaben und Anforderungen
GitHub Issues wird für die Verwaltung der Anforderungen und Aufgaben verwendet. GitHub Projects dient zur Planung und Fortschrittskontrolle.
